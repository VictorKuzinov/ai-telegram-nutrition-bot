# Nutriciolog Bot

Telegram-бот для ведения дневника питания, расчёта КБЖУ, генерации рецептов и меню, а также распознавания блюд по фотографии.

Проект написан на Python с использованием Aiogram 3. Бот сочетает собственную базу продуктов, USDA и AI-модели для обработки неизвестных блюд.

## Возможности

### Профиль пользователя

- ввод пола, возраста, роста и веса;
- выбор уровня физической активности;
- выбор цели питания;
- расчёт BMR;
- расчёт суточной калорийности;
- расчёт рекомендуемого количества белков, жиров и углеводов.

### Дневник питания

- добавление блюда вручную;
- расчёт КБЖУ по весу порции;
- просмотр дневника за текущий день;
- изменение и удаление записей;
- расчёт остатка калорий и БЖУ;
- история питания;
- статистика за 7 и 30 дней.

### Работа с AI

- генерация рецептов;
- генерация меню на день;
- распознавание блюда по фотографии;
- приблизительная оценка КБЖУ неизвестного блюда;
- повторный запрос к AI при ошибках;
- сохранение новых AI-оценок в очередь на проверку.

### База продуктов и блюд

- локальная база ингредиентов в JSON;
- поиск по русским и английским названиям и алиасам;
- интеграция с USDA;
- ручная проверка новых продуктов и готовых блюд;
- хранение неизвестных ингредиентов в отдельной очереди;
- защита от дубликатов и неконкретных наименований.

## Установка

### 1. Клонирование проекта

```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd ai-telegram-nutrition-bot
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

### 3. Активация окружения

Windows PowerShell:

```powershell
.venv\Scripts\Activate.ps1
```

Windows CMD:

```cmd
.venv\Scripts\activate.bat
```

Linux/macOS:

```bash
source .venv/bin/activate
```

### 4. Установка зависимостей

```bash
pip install -r requirements.txt
```

## Настройка

Создайте файл `.env` на основе `.env.example`.

Минимально требуется токен Telegram-бота:

```env
TELEGRAM_BOT_TOKEN=your_token
```

Для работы AI-функций и внешних источников добавьте необходимые ключи доступа, используемые в конфигурации проекта.

Секреты и токены не должны попадать в Git.


## Основные сценарии

### Добавление блюда

1. Открыть дневник.
2. Нажать `➕ Добавить`.
3. Ввести название блюда.
4. Ввести вес порции.
5. Если блюдо найдено в базе, КБЖУ рассчитывается автоматически.
6. Если блюдо не найдено, бот использует AI-оценку и сохраняет её для последующей проверки.

### Распознавание по фотографии

1. Выбрать `📷 Распознать блюдо`.
2. Отправить фотографию.
3. Подтвердить распознанное блюдо или исправить название.
4. Ввести вес порции.
5. Подтвердить сохранение в дневник.

### Создание рецепта

Бот запрашивает:

- название блюда;
- количество человек;
- ограничение по калориям;
- дополнительные пожелания.

После генерации рецепт проходит нормализацию и проверку структуры, ингредиентов и технологии приготовления.
